# android_desktop_mode example

Shows the live desktop-mode verdict and every signal the plugin read to reach it.

```bash
flutter run
```

Put the device into its desktop mode (dock it, plug in HDMI, toggle Samsung DeX, ...) and
the screen updates itself — no restart needed. The copy button in the app bar puts the
whole signal set on the clipboard, which is exactly what a
[device report](../CONTRIBUTING.md) needs.
